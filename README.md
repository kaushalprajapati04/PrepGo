# PrepGo – An Integrated Placement Preparation and Career Readiness Platform

## About the Project

PrepGo is a centralized web-based placement preparation and career readiness platform designed to help students prepare for campus placements and technical recruitment processes.

The platform brings multiple placement preparation activities into a single workspace, reducing the need to switch between different websites and tools for coding practice, aptitude preparation, resume building, interview preparation, company research, and job application tracking.

PrepGo aims to provide students with an organized preparation environment where they can improve their technical skills, monitor their progress, manage their resumes, and track their placement applications.

## Problem Statement

Students preparing for campus placements often depend on multiple disconnected platforms for coding practice, aptitude tests, interview questions, resume evaluation, company-specific preparation, and application tracking.

This creates several challenges:

- Preparation resources are scattered across different platforms.
- Students find it difficult to maintain consistent preparation routines.
- Resume management and ATS evaluation require separate tools.
- Tracking job applications and recruitment stages becomes difficult.
- Students lack a centralized system to monitor their preparation progress.

PrepGo addresses these challenges by integrating essential placement preparation activities into one platform.

## Key Features

### 1. Resume Builder and ATS Score Checker
- Create and manage professional resumes.
- Evaluate resumes using an ATS score checker.
- Identify areas for resume improvement.
- Save and access resume documents.

### 2. Document Management and Revision Notes
- Store personal preparation documents.
- Maintain short revision notes.
- Organize important study materials.
- Access saved resources when required.

### 3. Technical Interview Preparation
- Curated collection of approximately 150 technical interview questions.
- Questions covering important technical subjects.
- Organized preparation resources for interview revision.

### 4. SQL Practice
- Collection of approximately 50 SQL practice questions.
- Practice database-related concepts and queries.
- Improve SQL problem-solving skills.

### 5. Pattern-Wise Coding Practice
- Collection of approximately 250 coding questions.
- Questions organized according to programming patterns.
- Structured coding practice for technical assessments.

### 6. Online Code Compiler
- In-platform coding environment.
- Write and execute programs.
- Practice programming without switching between external tools.
- Supported programming languages and execution limits depend on the compiler integration.

### 7. Mock Interviews
- Practice interview scenarios.
- Rehearse technical interview questions.
- Improve interview preparation and confidence.

### 8. Aptitude Preparation
- Practice aptitude questions.
- Prepare for quantitative and logical reasoning assessments.
- Improve problem-solving abilities for placement examinations.

### 9. Company-Wise Preparation
- Access company-specific preparation resources.
- Understand recruitment preparation requirements.
- Organize preparation according to target companies.

### 10. Placement Application Tracker
- Maintain records of job applications.
- Track company names and job roles.
- Record application dates and recruitment stages.
- Manage upcoming actions and application progress.

### 11. Dashboard and Streak Tracking
- Centralized dashboard for placement preparation.
- Monitor preparation activities.
- Track daily learning consistency through streaks.
- Maintain an overview of preparation progress.

### 12. Feedback and Comments
- Provide feedback on the platform.
- Share suggestions and comments.
- Support continuous platform improvement.

### 13. Dark and Light Mode
- Switch between dark and light themes.
- Improve visual accessibility and user experience.
